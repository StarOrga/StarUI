# StarUI

Shared design system for the StarOrga / Star Citizen Companion ecosystem.
Consumed by StarOrga projects as a git dependency (`@starorga/star-ui`).

## Key Rules
- **Master source is the SCC desktop app.** Tokens/styles originate there and
  flow into this package — never edit a value here to diverge from the app.
- **LF only.** `.gitattributes` enforces `eol=lf` so consumers get byte-identical
  files to the master. Never weaken this — it underpins the zero-visual-change guarantee.
- **Edit `lib/*.css`, not `dist/`.** `dist/star-ui.css` is generated by
  `npm run build` (scripts/build.mjs) and committed for plain-HTML consumers.
- **Tag = release.** Bump `package.json` version + push a `vX.Y.Z` tag; consumers
  pin `#vX.Y.Z`. Patch = fix, minor = additive, major = breaking token change.

## Layout
`lib/` framework-agnostic CSS + JS utils · `shell/` desktop-app layout ·
`assets/` icons/tray/brand · `docs/` styleguide + catalog · `preview/` explorer ·
`dist/` generated bundle.

## Develop
`npm run build` — rebuild bundle · `npm run preview` — serve explorer at :4173.
